`nimblebrain-server-sdk` is the Python SDK for building MCP servers that run on NimbleBrain. Use it for a connector (a server alone, which the agent reaches through its tools) or for the server half of an app (a server plus its interface). It builds on FastMCP 4 and gives your server what a NimbleBrain host reads: tool annotations, change announcements, skills, facets, lifecycle handlers, host resources and the error contract. The interface half of an app is [Synapse](/build/packages/).

```sh
uv add nimblebrain-server-sdk
```

## Optional extras

The core installs nothing heavy. Add an extra when your server needs it:

| Extra | Install | For |
|---|---|---|
| `[db]` | `uv add 'nimblebrain-server-sdk[db]'` | A Postgres database shared by many tenants and workspaces, isolated by row-level security, with identity from the host. See [Data](/server-sdk/data/). |
| `[observability]` | `uv add 'nimblebrain-server-sdk[observability]'` | Metrics, structured logs and traces from one call. See [Observability](/server-sdk/observability/). |
| `[outbox]` | `uv add 'nimblebrain-server-sdk[outbox]'` | Notifications the host picks up, recorded in the same transaction as the change. Includes `[db]` and `[observability]`. See [Notifications](/server-sdk/notifications/). |
